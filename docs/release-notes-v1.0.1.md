## 这是什么

v1.0.1 是 v1.0.0（「可玩 · 好玩」首个完整可玩发行版）发布后的**修复轮**：针对玩家测评报告
汇总的 **14 项缺陷**逐项处理——含 2 个 P0 阻塞（跳棋对局永久思考、改规面板密钥欠费无
恢复路径）、5 个 P1 体验问题、4 项文案与视觉修正，并补上 3 项承诺功能（RPG 进度自动存档、
Esc 进棋种 hub、大地图 hub 入口）。

平台与运行方式不变：仍为 **Linux x64**，zip 平铺解压后直接运行 `ChessSage.x86_64`。

| # | 问题 | 修复 |

## 下载与运行

### Linux x64（本版唯一平台）

```bash
unzip ChessSage-Linux-x64-v1.0.1.zip
./ChessSage.x86_64
```

要求：Linux x86_64、OpenGL 3.2+（或 Mesa llvmpipe 软件渲染）。zip 为平铺结构，可执行文件即位于解压根目录；若下载后无执行位，先 `chmod +x ChessSage.x86_64`。

### 操作

- 启动后默认进入象棋对局；「返回棋种选择」或 Esc 进入棋种 hub 切换棋种；
- 对局中点「改写天规」打开作弊指令面板；
- 「六道轮回」进入 RPG 层（选关 / 技能 / 剧情 / 结局），进度自动存档；
- Esc 返回 hub。
