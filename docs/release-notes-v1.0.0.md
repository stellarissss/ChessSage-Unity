## 这是什么

《棋圣 · 六道轮回》（ChessSage）的 **Unity 重制版**首个发行版。原作是 Python + WebGPU 网页游戏，本仓库是其一比一重制，并在代码质量、性能、表现力上全面超出原版。

**本版的里程碑意义**：游戏从「能编译」跨到「**可玩、好玩**」——六个棋种全部可对弈、核心 USP（自然语言改规）首次以可玩证据呈现、RPG 六道轮回全链路走通、存档落地、大地图以 URP 2D 全面重制。

### 2. 核心 USP · AI 作弊改规指令面板

对局中用**自然语言**改写规则（「让马横着走」「兵变虎」），系统走完
**意图 → JSON Patch → Schema 校验 → 生效 → 业力结算 → 识破判定** 全链路：

- 10+ 预设指令一键填入；
- 改规前可见 JSON Patch diff 预览；
- 每次改规消耗业力（Δ = C × O^α，C/α 可被技能树下调）；
- 识破率随改规强度上升，识破触发有代价；
- 支持撤销。

### 3. 六道轮回 RPG 层

- 6 道关卡选关、4 分支 × 3 层技能树；
- 剧情对白 + 分支选择；
- 双结局（真结局 / 识破结局）；
- 记忆碎片回顾。

### 4. 存档系统

3 槽位、schema 版本迁移、SHA-256 校验和、损坏数据恢复。

### 5. 六道大陆大地图（URP 2D 全面重制）

- 等距地形 + 16×16 分块流式加载（0 GC / 帧）；
- 6 种地形 + 过渡羽化 + 瓦片变体（消灭格子化）；
- Poisson-disk 植被撒点 + 地标（城镇/寺庙/山口/奇观）；
- 河流 / 湖泊 / 桥梁 / 道路；
- 昼夜循环 + 雾 + 天气 + 探索反馈；
- 内置性能面板（FPS / DC / 顶点数）。

### 6. Unity 特有功能

- URP 2D Renderer（实时光照 + 雾）；
- 模块化四程序集（Core 零引擎依赖 → 单测可引擎外跑）；

## 下载与运行

### Linux x64（本版唯一平台）

```bash
unzip ChessSage-Linux-x64-v1.0.0.zip
cd ChessSage-Linux-x64
./ChessSage.x86_64
```

要求：Linux x86_64、OpenGL 3.2+（或 Mesa llvmpipe 软件渲染）。

### 操作

- 启动后进入棋种 hub → 选择棋种对局；
- 对局中点「改写天规」打开作弊指令面板；
- 「六道轮回」进入 RPG 层（选关 / 技能 / 剧情 / 结局）；
- Esc 返回 hub。

## 已知限制

| 限制 | 说明 |
|:--|:--|
| **仅 Linux x64** | Windows 交叉编译模块（WindowsStandaloneSupport）在本环境不可得，Windows 版待模块就位后补充 |
| **占位美术** | 视觉资产为程序化生成的占位实现，正式美术规格已就位（`docs/art/`），替换为纯资源动作 |
| **AI 改规需密钥** | 自然语言改规走 DeepSeek API，无密钥时面板会明确提示而非静默失败；预设指令在无密钥时仍可演示本地规则替换 |
| **音频** | FMOD 接口就位，BGM/音效内容待正式制作 |
| **移动端 / WebGL** | 未验证，本版面向桌面 |
