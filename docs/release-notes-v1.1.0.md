# v1.1.0 —— AI Agent 驱动作弊（核心重制）

> 发布日期：2026-10-24 · 平台：Linux x64（Windows 构建另行提供）

## 一句话

把原来的「双层级 LLM 流水线」整体换成**一个 AI Agent + 8 个进程内工具**：玩家说一句话，天道自己去读棋盘、查规则、改配置、交预览——更快、更透明，业力还是那个业力。

## 核心变化

### 1. 作弊引擎重制：Agent 取代 ChatAI / CodeAI

- 删除「意图分类（A–F）→ 业力评估 → 逐 action 生成补丁」三段式，改为单一 Agent 的 tool-calling 循环：
  读棋盘 → 查配置切片 → 应用 JSON Patch → 提交预览，一个循环内完成。
- 8 个进程内工具（MCP 风格，JSON Schema 描述）：
  `get_board_state` / `get_config_slice` / `get_karma_state`（只读）、
  `move_piece` / `undo_last_change` / `commit_preview`（常规）、
  `apply_config_patch` / `set_objective`（特权写，路径白名单 + Schema 硬校验 + 原子事务）。
- 技能门控从「分类 A–F」换成「**天机型谱**」工具/作用域门控，由原有技能节点推导，**旧存档完全兼容**。

### 2. 业力定价：从「LLM 猜档位」改为「token 实耗」

- 业力 = 凸函数 f(T_eff) × 波动（0.8–1.3，含高档激增）× 技能折扣 × **补丁作用域深度权重**，clamp[1,120]。
- 作用域权重（界面 1.0 / 棋盘 2.9 / 铸子 1.85 / 规则 3.35）是补丁落点的**机械属性**，不是意图分类——同样的 token 消耗，改规则比改配色更贵。
- 真实 API 校准 197 次后的六档落点：**E 1 / D 19 / B 39 / A 47 / C 55 / C+ 120**，全部落回旧价目带（8–23 / 23–53 / 30–60 / 45–90 / 75–120），难度与旧版对齐。
- 零写入（闲聊/只读查询）恒 1 点；失败卡不收费。

### 3. 透明轨迹与「收手」

- 处理中实时显示：轨迹（正在读棋盘/定位规则/落下改数）、已耗 token（思索与改数拆分）、业力预估、已用时 / 20s。
- **收手（Esc）**：随时跳车。有补丁给半成品预览（按已耗 token 计价），没有则失败卡不收费。
- 业力触顶：计数器转红警示「再推也是顶格，确认时按上限放行」——不拦截，由你决断。

### 4. 性能：20 秒硬顶

- 单次任务硬超时 20 秒；典型任务 P50 约 4–8 秒。
- 手段：系统提示 + 工具 schema 字节级稳定以吃满前缀缓存、thinking 分级（工具轮 low / 终轮 high）、轮次压缩（生产 4 轮）。
- 到点收尾：有改动 → 半成品预览按实耗计价；无改动 → 不收费。

### 5. 稳定性

- 修复 thinking 历史缺少 `reasoning_content` 导致的 HTTP 400：引擎自动降级重试一次，不再中断整批。
- 离线/网络失败：连续两次失败自动切离线预置指令，零 LLM 调用。
- 预置指令与自然语言并存：预置明码标价（UI 标注「预置价」），自然语言按实耗计费。

## 兼容性

- v1.0.1 存档可直接读取；旧派生键 `allowed_classifications` 为无害字段。
- 旧「改规栈 / 撤销规则 / 离线预置 / 两段式确认」契约不变：提交不改状态，确认才扣费。

## 已知问题（v1.1.1 处理）

1. C+ 铸子常同时触发棋盘写入，作用域取最大导致业力常顶格 120（旧价上沿，仍在带内）。
2. 技能「高级规则（t2b）」在新定价轴下暂无独立增益（规则类改动已默认畅通），将重做为实际减费或深度增益。
3. UI 仅经软件渲染截图取证（处理态/顶格/到点两态），尚未做真人 Playtest。

## 安装

1. 解压 `ChessSage-Linux-x64-v1.1.0.zip`；
2. `chmod +x ChessSage.x86_64` 后运行；
3. 可选：在可执行文件旁放 `config.json`（`api_key` / `base_url` / `model`）或设置 `DEEPSEEK_API_KEY` 环境变量覆盖内置配置。
