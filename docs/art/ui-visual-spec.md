# ChessSage-Unity · UI 视觉规格

> 适用对象：棋盘、HUD、面板（作弊/棋种 hub/RPG 表现层）、菜单。
> 制定原则：占位美术优先统一语言；正式美术只需在 spec 层面替换 token，**不需要改组件 API**。
> 制定日期：2026-10-14 ｜ 制定人：林绘澄（art-director）· 汇编：游承峰

---

## 1. 调色板（Color Tokens）

| Token | HEX | 用途 |
|:--|:--|:--|
| `--bg-0` | `#0E1320` | 全局深色背景（场景外、面板底） |
| `--bg-1` | `#171E2E` | 面板背景、卡片底 |
| `--bg-2` | `#1F2A40` | 选中态、悬停态、输入框焦点 |
| `--text-0` | `#F3F3EE` | 主文本 |
| `--text-1` | `#A9B0BD` | 次要文本 / 标签 |
| `--text-2` | `#6B7280` | 禁用 / 占位文本 |
| `--accent` | `#FFC857` | 强调（高亮、可点击提示、回合标识） |
| `--accent-soft` | `#FFE7A8` | 强调柔化（hover / focus ring） |
| `--side-red` | `#D94336` | 红方阵营（象棋红、动物棋红等） |
| `--side-red-deep` | `#6F1A12` | 红方描边 |
| `--side-white` | `#F2F2EE` | 白方阵营 |
| `--side-white-deep` | `#3D3F46` | 白方描边 |
| `--side-black` | `#3A3E48` | 围棋/黑白棋黑方 |
| `--side-black-deep` | `#0F1014` | 黑方描边 |
| `--ok` | `#3DC16F` | 合法落点 / 成功反馈 |
| `--warn` | `#FFB14E` | 警告（业力临界、识破风险） |
| `--danger` | `#FF5C5C` | 提子 / 错误 / 识破触发 |
| `--info` | `#5AA6FF` | 信息（新增关卡、技能解锁提示） |

> 所有组件读取上述 token 而非硬编码颜色（占位实现阶段用 `Color` 常量统一在 `PlaceholderArt` 与面板脚本头部）。

## 2. 字体

| Token | 字体 | 用途 |
|:--|:--|:--|
| `--font-display` | 思源宋体 / Source Han Serif / Noto Serif CJK | 关卡标题、剧情对白（"庄严"语感） |
| `--font-body` | 思源黑体 / Source Han Sans / Noto Sans CJK | 面板正文、按钮、提示 |
| `--font-mono` | JetBrains Mono / Sarasa Mono SC | 业力公式 / JSON Patch diff |
| 字号档 | 12 / 14 / 16 / 18 / 22 / 28 / 36 | 12 标签 · 14 正文 · 16 强调正文 · 18 副标题 · 22 标题 · 28 大标题 · 36 剧情大标题 |

> 占位阶段：`UnityEngine.UI.Text` + 默认 Arial（Linux 自带 fallback）。正式美术阶段统一替换为 `TMP_Text` + TMP_FontAsset。

## 4. 棋盘表现规范

### 4.1 视觉骨架

```
┌───────────────────────────┐
│  状态条（HUD）             │  ← 业力/识破/回合/目标
├───────────────────────────┤
│                           │
│      ┌─────────────┐      │
│      │   棋盘       │      │  ← 视口中心
│      │   视图       │      │
│      └─────────────┘      │
│                           │
├───────────────────────────┤
│  操作/提示面板            │  ← 因模式而异（作弊/HUD/落子提示）
└───────────────────────────┘
```

### 4.2 网格

| 参数 | 值 |
|:--|:--|
| 单格像素（程序化） | 64×64 |
| `pixelsPerUnit` | 64 |
| 描边像素 | 0（纯色块，靠 `CellAlt` 错色产生格线感） |
| 选区高亮 | `SelectRing` sprite（黄环），半径 96×96 |

### 4.3 棋子

7 种形状 × 3 种阵营 = 21 种 sprite，全部由 `PlaceholderArt.BuildPiece` 程序化生成：

| 形状 | 关联棋子 | 形状记忆点 |
|:--|:--|:--|
| Diamond | 将/帅、围棋子 | 高对比、居中 |
| Hexagon | 士/仕 | 六角"防御"感 |
| Pentagon | 马 | 朝向箭头（隐喻前进） |
| Square | 车/战车 | 直线撞击 |
| Circle | 炮 | 弧线冲击 |
| Cross | 兵/卒 | + 字，象征"前线" |
| Elephant | 象 | 鼻形凸起（顶部带尖角） |

每阵营：body + rim 双色，rim 内缩 2px 作描边（确保色盲区分）。

## 5. HUD 组件库

### 5.1 状态条

- 永远位于屏幕顶 1/12 高度，深色 `bg-1` 半透明；
- 必含 5 项：业力槽、识破槽、回合数、目标、菜单按钮；
- 业力槽颜色随档位变化：`>50% accent` / `20–50% warn` / `<20% danger`；
- 数值变化时数字"上滚 + 淡入"动画 250 ms（占位阶段先不实现，正式美术阶段补）。

### 5.2 提示卡片

- 圆角 12、`bg-1` 底、`accent` 1px 描边；
- 最大宽 480，padding `--space-4`；
- 出现/消失 200 ms 缩放 + 透明度。

### 5.3 按钮

| 类型 | 圆角 | 底色 | 文字色 | hover | active |
|:--|:--|:--|:--|:--|:--|
| Primary | 8 | `accent` | `bg-0` | `accent-soft` | `accent` 降亮度 10% |
| Secondary | 8 | `bg-2` | `text-0` | `bg-2` 提亮 5% | `bg-2` 降亮度 5% |
| Danger | 8 | `danger` | `text-0` | `danger` 提亮 5% | `danger` 降亮度 10% |
| Ghost | 8 | 透明 | `accent` | `accent-soft` 底 | `accent` 底 |

最小命中区 32×32（移动端规范）。

## 6. 面板规格

### 6.1 通用布局（cheat / rpg skill / rpg story / rpg ending 共用）

```
┌─ 标题区 (--space-4 padding) ────────────┐
│  ⚡ 改写天规 / ⚙ 技能树 / 📜 剧情 / …    │ ← 16 标题 + 22 副标题
│  副标题（一行说明）                       │ ← 14 文本-1
├──────────────────────────────────────────┤
│                                          │
│  内容区（自适应高度，可滚动）              │
│                                          │
├──────────────────────────────────────────┤
│  操作区（确认/取消 / 关闭）               │ ← Primary 在右
└──────────────────────────────────────────┘
```

### 6.2 特殊：作弊指令面板（核心 USP）

```
┌ 改写天规 ───────────────── 收起 ✕ ┐
│ 离线模式：无法连接天道…               │ ← 离线/在线状态横幅
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ 输入一句话，…                    │ │ ← 输入框（占 100% 宽）
│ └──────────────────────────────────┘ │
│                                      │
│ 试试（点击直接填入）：                 │ ← 标题
│ ┌──────┐┌──────┐┌──────┐┌──────┐    │ ← 预设按钮
│ │让马横││兵变虎││车飞楚││…      │    │   最多 4 列自适应
│ └──────┘└──────┘└──────┘└──────┘    │
│                                      │
│ 常用 · 历史                          │
│ ┌──────┐┌──────┐┌──────┐┌──────┐    │
│ │预设A ││预设B ││预设C ││预设D │    │
│ └──────┘└──────┘└──────┘└──────┘    │
│                                      │
│              [ 撤销 AI 修改 ] [ 施展 ] │
└──────────────────────────────────────┘
```

- 顶部为标题 + 关闭按钮（右上角 32×32）；
- 第二行是状态横幅（连/离线、当前业力/识破值）；
- 输入框：`bg-2` 底，`accent` focus ring；
- 预设按钮：Secondary 样式，4 列等宽，可横排多行；
- 底部操作：左 Secondary "撤销"，右 Primary "施展"。

### 6.3 RPG 表现层

| 视图 | 关键差异 |
|:--|:--|
| 关卡选择 | 6 道关卡大卡片网格（3×2），每卡含主题色 + Boss 名字 + 完成度 |
| 技能树 | 4 分支 × 3 层，已解锁/可解锁/未解锁 3 态视觉区分 |
| 剧情对白 | 大字号 36 居中显示对白，下方"继续▼"提示 |
| 结局 | 全屏淡入黑底大字标题（36）+ 描述（18）+ 1 个返回按钮 |

## 7. 动效（占位阶段可选，正式美术阶段必备）

| 场景 | 动效 | 时长 |
|:--|:--|:--|
| 棋子落子 | 落点 → 弹起 12px → 落定（ease-out） | 180 ms |
| 提子 | 缩 1→0 + 旋转 0→90° | 220 ms |
| 翻转（黑白棋） | Y 轴 0→180 | 280 ms |
| 面板打开 | 缩 0.96→1 + 透明度 0→1 | 200 ms |
| 面板关闭 | 缩 1→0.96 + 透明度 1→0 | 160 ms |
| 业力变化 | 数字 tween + 槽条宽度 tween | 350 ms |

---

## 8. 可访问性（Basic 级）

- **色盲安全**：棋子阵营颜色 + 形状双重区分（红=红+菱/方/圆；白=白+交叉等）；
- **焦点环**：键盘焦点统一 `accent-soft` 2px outline；
- **字号缩放**：HUD/正文 16/18 两档切换，预设快捷键 `+/-`；
- **高对比模式**：开关切换 `bg-0` `#000` + `text-0` `#FFF`（占位阶段不实现，spec 留口）；
- **动效关闭**：用户偏好"减少动效"时，关闭所有缩放/旋转动画。

## 9. 与现有代码的对应

| Spec 元素 | 现有实现 |
|:--|:--|
| 调色板（阵营色） | `PlaceholderArt.BuildPiece` switch（`red`/`white`/`black`） |
| 形状系统 | `PlaceholderArt.Shape` 枚举 + `ShapeFor` 映射 |
| 状态条 HUD | `GameFlowHud`（`业力/识破/回合/目标/返回` 五件套） |
| 作弊指令面板 | `CheatCommandPanel` + `CheatHud`（实现完整，见 `docs/m6-m8-report.md`） |
| RPG 表现层 | `Presentation/Samsara/`（`RpgLevelSelect` / `SkillTreeView` / `DialoguePanel` / `EndingOverlay`） |
| 棋盘渲染 | `BoardView` + `GameScreen` |

> 正式美术阶段：只需把 `PlaceholderArt` 内的 `Color(...)` 替换为图集 sprite，并把 `GameFlowHud`/`CheatCommandPanel` 等组件的硬编码颜色迁到本 spec token（Color ScriptableObject 或 ThemeManager）。
