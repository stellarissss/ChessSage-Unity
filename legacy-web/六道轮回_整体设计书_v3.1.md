## 一、游戏概述

### 1.1 一句话定位

玩家是叛逆高中生林夜，因长期下棋作弊积累恶业而坠入内心投射的六道轮回。从地狱道逐级轮转至天道，每道由 5-6 个预制关卡组成，最后一关为守道者 Boss。玩家通过正常下棋推进局势，可用自然语言向 AI 发出作弊指令实时改写棋盘 / 棋子 / 规则 / UI / 机制；作弊增业障、下棋可消业；业力超阈会非线性涨识破。被识破者业力与识破概率锁死为 0，但保留永久进度，待通关六道后触发天道 Boss 战。

### 1.2 四大支柱

| 支柱 | 描述 |
|:----|:-----|
| **六种棋类** | 黑白棋（地狱）、跳棋（饿鬼）、动物棋（畜生）、象棋（人道）、围棋（阿修罗）、五子棋（天道），每棋独立进程，互不干扰 |
| **AI 作弊改规** | 自然语言一句话改写棋局，AI 实时生成 JSON Patch 应用到配置（灵活编码 Flexible Coding） |
| **Roguelike 进度** | 33 关 + 6 Boss + 沙盒；章节（=道）内业力溢出叠加；被识破重置非永久进度；通关获技能点永久保留 |
| **轻 RPG 叙事层** | 主角人格侧面化为六道守道者；悟道 / 堕落 / 理性 / 情感四维度选择；6 个记忆碎片 + 5 种结局 |

### 1.3 核心体验矩阵

| 体验维度 | 描述 |
|:--------|:-----|
| **作弊的爽** | 自然语言一句话改写棋局，AI 实时生成 JSON Patch 应用到配置 |
| **业障的压** | 作弊越多业力越高，必须靠下棋消业才能继续作弊 |
| **透支的怕** | 业力超阈值后非线性涨识破，溢出 100 点 = 识破概率 +100% |
| **章节的连** | 同一道内每关溢出叠加给下一关，迫使玩家"控制业力" |
| **技能的成长** | 通关获得技能点，4 分支 × 3 层技能树持久保留 |
| **叙事的引** | 六道即人格六面，守道者即主角的投影，每关剧情推动主角弧光 |
| **被识破的悟** | 识破后只清当前进度，技能树 / 技能点 / Boss 记录 / 成就保留；且新增"天道 Boss 战"终局挑战 |
| **多结局的复** | 悟道 / 堕落 / 轮回 / 真我 / 识破 5 种结局，鼓励多周目探索 |

### 1.4 与 v2.0 的关键差异

| 维度 | v2.0（业障模型） | v3.0（叙事融合 + 天道终战） |
|:----:|:-----------------|:---------------------------|

## 二、核心玩法循环

### 2.1 主循环图

```
下棋消业 → 业力空间扩大 → 花业力作弊 → 改写局势取胜 → 通关获技能点
   ↑                                              │
   └── 胜/负都把业力溢出叠加给本道下一关 ──────────┘
                                                  │
                                  换道/被识破 → 溢出清零
                                                  │
                                  ┌───────────────┴───────────────┐
                                  ▼                               ▼
                          正常通关：升道                    被识破：业力 & 识破概率锁死 0
                          六道全通 → 5 种结局分支            继续通关六道 → 天道 Boss 战
```

### 2.2 单局流程详解

1. **关卡开始**：业力 = `max(0, initial_karma=50 - 净身减免) + 本道溢出叠加`；剧情开场对白播放
2. **下棋消业**：吃子 / 将军 / 三连 / 翻转 / 跳子等事件触发 `KarmaSystem.recover()`，减少业力
3. **作弊增业**：玩家输入自然语言指令 → 两级 AI（Intent Parser + Karma Assessor）并行评估 → 业力上限拦截 → JSON Patch 生成 → Schema 校验 → 应用配置
   - 评估值 ≤ 120：增加业力，可继续执行
   - 评估值 > 120：直接拦截，不予执行，业力不变
4. **溢出识破**：业力 > 安全阈值（120）的部分非线性增加本道识破概率；每次 AI 修改后 roll 一次，命中即被识破
5. **关卡结束**：胜负都执行 `record_level_end()`，溢出量 = `max(0, 当前业力 - 安全阈值)`，叠加给本道下一关
6. **通关奖励**：技能点（基础 +1 / 无作弊 +2 / 未透支 +1 / Boss 首杀 +1 / 沙盒 +1，单关最多 +5）
7. **道通关**：击败守道者 → 关键选择（影响悟道/堕落值）→ 升降道（无透支跳级 +2 / 普通关升 +1）→ 解锁沙盒

### 2.3 Roguelike 要素

- **永久保留**：技能树、技能点、Boss 击败记录、已通关道、沙盒、成就、记忆碎片、已解锁结局
- **重置**：当前道、当前关卡、本道业力溢出叠加、识破概率（除识破结局锁死 0 的情况）
- **多周目**：技能树叠加使后期 build 多样化；二周目起守道者台词随累计悟道/堕落值变化

## 三、业力系统

### 3.1 业障模型定义

业力 = 玩家作弊产生的"业障"。初始为 50，安全阈值为 120，单次作弊业力增量上限为 120。业力最小为 0，最大无硬上限（但溢出会触发识破）。

### 3.2 关键参数

| 参数 | 字段 | 默认值 | 说明 |
|:----:|:-----|:------:|:-----|
| 初始业力 | `initial_karma` | 50 | 关卡起始业力（受"净身"技能减免） |
| 安全阈值 | `karma_max` | 120 | 超出后识破概率非线性增长 |
| 单次上限 | `karma_single_max` | 120 | 单次作弊业力增量上限 |
| 本道溢出叠加 | `realm_overshoot_carryover` | 0 | 本章节上一局溢出量，叠加到下一局起始 |

### 3.3 增业规则（作弊）

**触发条件**：AI 作弊指令成功执行（`type=applied` 或 `type=fun`）
**评估机制**：`KarmaAssessor.assess()` 调用 DeepSeek 评估
**评估输出**：1-120 整数
**边界处理**：`amount > 单次上限` → 拦截，业力不变

#### 3.3.1 意图分类价目表

| 分类 | 含义 | 业力区间 | 技能解锁 |
|:----:|:-----|:--------:|:--------:|
| E | 闲聊 / 搞笑 | 1（固定） | 默认 |
| D | 界面修改 / 外观 | 8-23 | `cheat_mastery_t1b` |
| A | 机制修改 | 30-60 | 默认 |
| B | 棋盘变换 / 棋子位置 | 23-53 | 默认 |
| C | 规则修改 / 棋子走法 | 45-90 | 默认 |
| C+ | 创建新棋子 | 75-120 | `cheat_mastery_t1a` |
| F | 失败 / 拒绝 | 0 | - |

**强度倍数**：改 1 项 ×1.0，改 2 项 ×2.0，改 3+ 项 ×3.0

**边界**：评估值下限 1 点，上限 120 点（= `karma_single_max`，超出即拦截）
**局势调整**：大优 ×1.2，劣势 ×0.9
**守道者加价**：畜生道"高等级棋子 +20 业力"

### 3.4 消业规则（下棋事件）

**触发条件**：吃子 / 将军 / 三连 / 翻转 / 跳子等事件
**事件定义**：`configs/karma_events.json`
**消业公式**：`实际消业 = 事件基础值 × karma_recover_multiplier`（"业力潮汐"技能 +30%）
**边界处理**：业力最小为 0

#### 各棋类消业事件表

| 棋类 | 事件类型 | 数值（点） |
|:----|:--------|:----------|
| **象棋 xiangqi** | capture_pawn / capture_medium / capture_rook | 8 / 15 / 25 |
|              | check / checkmate / pawn_cross / captured | 20 / 35 / 10 / 5 |
| **围棋 weiqi** | capture_small / capture_large / life | 10 / 20 / 15 |
|              | captured / corner / endgame | 5 / 12 / 8 |
| **五子棋 wuziqi** | three / four / block_three / block_four | 10 / 20 / 8 / 18 |
|                | double_three / win | 15 / 35 |
| **动物棋 dongwuqi** | capture_normal / capture_overrank / captured | 10 / 25 / 5 |
|                  | approach / win | 12 / 35 |
| **跳棋 tiaoqi** | jump_3 / jump_5 / home | 10 / 20 / 15 |
|              | single_move / all_home | 3 / 35 |
| **黑白棋 heibaiqi** | flip_small / flip_medium / flip_large | 8 / 15 / 25 |
|                  | corner / flipped / win | 20 / 5 / 35 |

### 3.5 溢出叠加机制（章节 = 道）

**章节定义**：六道轮回中的一个"道"为一个章节。

#### 3.5.1 关卡开始

```python
level_karma = max(0, initial_karma - initial_karma_reduction) + realm_overshoot_carryover
```

- `initial_karma_reduction`：净身技能减免（默认 0，技能解锁后 25）
- `realm_overshoot_carryover`：本道上一局溢出叠加（默认 0）

#### 3.5.2 关卡结束（胜负都执行）

```python
overshoot = max(0, level_karma - karma_max - karma_max_bonus)
realm_overshoot_carryover = overshoot
```

#### 3.5.3 章节切换

```python
set_realm(new_realm):
    current_realm = new_realm
    current_level = 0
    realm_overshoot_carryover = 0   # 换道清零
```

#### 3.5.4 被识破

```python
on_detection():
    # 不再立即 reset_on_detection，改为锁死
    level_karma_locked = 0          # 业力锁死为 0（玩家暂时无法增业，但也不需消业）
    realm_detections[current_realm] = 0.0  # 识破概率锁死为 0
    detection_triggered = True      # 标记进入"识破结局"分支
    # 保留：技能树、技能点、Boss 记录、已通关道、成就、记忆碎片、已解锁结局
    # 玩家继续通关六道，结尾触发天道 Boss 战
```

### 3.6 退还机制

| 场景 | 处理 |
|:-----|:-----|
| E 类被 ChatAI 拒绝 | 退还 1 点 |
| 修改失败（`type=rejected`） | 全额退还（业力不增加） |
| 修改错误（`type=error`） | 全额退还 |
| 评估超出单次上限 | 直接拦截，业力不变 |
| 修改成功（`type=applied`） | 增加业力 |
| 闲聊成功（`type=fun`） | 增加 1 点 |

### 3.7 设计意图

- **业障模型**：作弊不是消耗资源，而是积累"罪业"。这与佛教"业障"概念一致，作弊越多越接近天道识破。
- **章节叠加**：玩家在本道内必须控制每局业力，否则溢出会累积到下一局。迫使玩家"克制作弊"。
- **胜负都叠加**：失败后重试也要承担溢出，避免"故意失败重置业力"的作弊策略。
- **换道清零**：新章节新开始，避免长期累积导致后期不可玩。
- **识破锁死**：识破不再直接重置全部进度，而是触发"识破结局"分支——业力锁死为 0 后玩家反而可以"轻松"通关六道，但结尾必须面对天道 Boss 战的硬性挑战。这是对"逃避作弊"玩家的最终审判。

## 四、识破系统

### 4.1 公式

```
Δ = C × O^α
```

| 参数 | 含义 | 默认值 | 技能调整 |
|:----:|:-----|:------:|:---------|
| O | 业力超出安全阈值的部分 | - | - |
| C | 惩罚系数 | 0.1 | 藏锋（stealth_t1）→ 0.07 |
| α | 非线性指数 | 1.5 | 缓冲（karma_capacity_t3a）→ 1.3 |
| Δ | 识破概率增量（%） | - | - |

### 4.2 校准表（默认 C=0.1, α=1.5）

| 溢出量 O | Δ（%） | 累计识破概率* |
|:--------:|:------:|:-------------:|
| 10 | 3.16 | 3.16% |
| 20 | 8.94 | 8.94% |
| 30 | 16.43 | 16.43% |
| 50 | 35.36 | 35.36% |
| 80 | 71.55 | 71.55% |
| 100 | **100.00** | 100% |
| 150 | 183.71 | 100%（封顶） |

\* 累计识破概率为本道所有溢出事件 Δ 之和，封顶 100%。

**校准目标**：超出 100 点 = 识破概率增长 100%。

### 4.3 概率判定流程

```
1. 玩家作弊 → increase_karma(amount)
2. 计算 overshoot = max(0, level_karma - karma_max)
3. 若 overshoot > 0：
   a. 计算 Δ = C × overshoot^α
   b. 首次透支免判（stealth_t2a）→ Δ = 0，标记已用
   c. 迷雾（stealth_t3b）→ 识破 > 70% 时 30% 概率 Δ = 0
   d. realm_detection += Δ（封顶 100）
   e. record_overdraft()
4. roll = random(0, 100)
5. 若 roll < realm_detection：
   a. 金蝉脱壳（stealth_t3a）→ realm_detection *= 0.5，免死一次
   b. 否则 → 触发识破（不再 reset，改为锁死）
```

### 4.4 道级全局变量

识破概率是**道级全局变量**（`realm_detections[realm]`），跨关卡保留：
- 同一道内每关的识破概率累计
- 换道时新道从 0 开始
- **新**：被识破时该道识破概率锁死为 0（玩家暂时无法被再次识破，进入"识破结局"分支）

### 4.5 被识破后的处理

#### 4.5.1 旧规则

```python
reset_on_detection():
    # 重置所有非永久进度
    realm_overshoot_carryover = 0
    level_karma = initial_karma
    current_realm = "hell"
    current_level = 0
    realm_detections = {all: 0.0}
```

#### 4.5.2 新规则

```python
on_detection():
    # 不立即重置进度，而是进入"识破结局"分支
    level_karma = 0                          # 业力锁死为 0
    realm_detections[current_realm] = 0.0    # 本道识破概率锁死为 0
    detection_triggered = True               # 全局标记
    karma_locked = True                      # 业力锁死标记（阻止 increase_karma 生效）
    # 玩家可以继续下棋推进关卡，但作弊指令将被拒绝（karma_locked）
    # 通关六道后，强制进入天道 Boss 战
```

#### 4.5.3 识破结局触发条件

- 玩家在任意一道被识破一次（roll < realm_detection 且无金蝉脱壳）
- 后续仍需通关所有六道
- 通关六道后**强制**进入天道 Boss 战（不可选择其他结局）

### 4.6 天道 Boss 战

#### 4.6.1 触发条件

- 玩家在六道轮回中至少被识破过 1 次
- 玩家通关所有六道（含被识破后业力锁死状态下的剩余道）
- 通关天道（禅定者）最后一关后自动触发

#### 4.6.2 战斗规则

| 维度 | 设定 |
|:----:|:-----|
| **棋类** | 传统象棋（xiangqi） |
| **作弊** | **完全禁止**——业力锁死为 0、所有作弊指令被拒 |
| **特殊规则** | 天道无士（advisor=0），士位全部被车取代（chariot=4，共 4 车）；玩家方为标准布局 |
| **AI 难度** | `difficulty=nightmare`，`search_depth=6`（最高） |
| **回合限制** | 无（不受 20 回合限制） |
| **失败处理** | **无限重试**——失败不退出，可重新对弈 |
| **胜利意义** | 通过纯棋力击败"天道"——证明即使无作弊，玩家也能赢得尊重 |

#### 4.6.3 剧情定位

天道 Boss 战是"识破结局"的核心剧情节点——玩家曾经靠作弊逃避，如今必须以纯粹的实力面对自己。这呼应了"规则是束缚还是保护"的核心命题：当一切作弊手段被剥夺，玩家能否凭真本事获胜？

#### 4.6.4 实现要点

- 复用 `xiangqi/main.py` 的标准象棋逻辑
- 在 `samsara_state.json` 新增 `heaven_boss_battle` 状态字段
- 修改 `configs/tiandao_boss.json` 中天道方棋子配置：`advisor=0`、`chariot=4`（士位被车取代，非走法变更）
- 前端禁用作弊输入框，显示"天道之下，作弊无效"提示
- 失败时显示"再战"按钮，不消耗任何进度

### 4.7 设计意图

- **非线性增长**：α=1.5 使小透支可控（O=10 仅 +3%），大透支几乎必死（O=100 必死）。鼓励"小步透支"而非"豪赌一次"。
- **道级而非关卡级**：识破概率跨关保留，迫使玩家在整道内控制作弊节奏。
- **技能可降低**：藏锋（C↓）、缓冲（α↓）、首次免判、迷雾、金蝉脱壳，给玩家"作弊流"build 空间。
- **识破锁死**：识破不再粗暴地"轮回重来"，而是触发"识破结局"——业力锁死反而使后续通关变容易，但天道 Boss 战是终极考验。这给玩家提供了"作弊被识破→用真本事证明自己"的叙事弧光。

### 6.4 升降道规则

```python
def advance_realm():
    if levels_passed >= total_levels:
        mark_realm_completed(current_realm)
        unlock_sandbox(current_realm)
        if overdraft_count == 0:
            # 无透支通关，跳级 +2
            new_index = min(current_index + 2, len(REALMS) - 1)
            direction = "up_2"
        else:
            # 普通通关，升 1 级
            new_index = current_index + 1
            direction = "up_1"
        set_realm(REALMS[new_index])  # 换道，清零溢出叠加
```

- **跳级 +2**：鼓励玩家"克制作弊"，无透支通关可加速进度

### 6.6 被识破后的关卡进度

被识破后玩家不立即重置，而是：
- 业力锁死为 0，作弊指令被拒

- 通关六道后触发天道 Boss 战

## 七、轻 RPG 叙事层

> **状态：已实现**（详见《轻RPG化剧情实现草案_v1.4.md》）
> v3.0 将叙事层与玩法系统正式融合为整体设计的一部分。

### 7.1 精神主旨：规则与自由的辩证

**核心命题**：
> "规则是束缚，还是保护？打破规则是自由，还是堕落？"

主角林夜是叛逆的高中生，质疑一切既定规则。当他真的打破所有规则、堕入六道轮回之后，才一点点明白：
- 没有规则的世界，剩下的只有混沌与痛苦；
- 真正的自由，不是打破一切规则，而是理解规则之后做出选择；
- 规则与自由并非对立，而是一体两面——规则是自由的形状，自由是规则的灵魂。

**主题层次**：
1. **表层**：叛逆少年对抗规则的爽感（作弊玩法）
2. **中层**：反思"打破规则"的代价与边界（业障系统）
3. **深层**：探讨规则与自由的辩证关系（六道悟道）
4. **现实映射**：对教育体制、社会规训的温和讽刺与反思

### 7.2 剧情架构：六道 = 六个人格侧面

六道并非真实存在的世界，而是主角内心的投射。每一道都对应主角人格的一个侧面，每一个守道者都是主角某一部分人格的化身。

| 道 | 人格侧面 | 棋类隐喻 | 守道者 |
|:--:|:--------|:--------|:------|
| 地狱道 | 愧疚 · 过去的错误 | 黑白棋（翻转 = 悔恨的反复折磨） | 翻覆者 |
| 饿鬼道 | 贪婪 · 永不满足的欲望 | 跳棋（无尽之路 = 永远走不到尽头） | 饕餮者 |
| 畜生道 | 本能 · 弱肉强食的原始冲动 | 动物棋（等级秩序 = 食物链） | 秩序者 |
| 人道 | 理性 · 算计与权衡 | 象棋（最平衡 = 最理性的算计） | 算计者 |
| 阿修罗道 | 愤怒 · 叛逆与对抗欲 | 围棋（战场 = 愤怒的战场） | 狂乱者 |
| 天道 | 真我 · 释然与和解 | 五子棋（五连登仙 = 圆满） | 禅定者 |

通关六道，就是与自己的每一部分对话、对峙、和解、整合的过程。

### 7.3 选择系统：四维度人格变量

| 维度 | 字段 | 来源 | 影响 |
|:----:|:-----|:-----|:-----|
| **悟道值** | `enlightenment_value` | 每道 Boss 战后选择（±3）、每道第 3 关选择（±1） | 影响结局走向、守道者台词温和度 |
| **堕落值** | `corruption_value` | 每道 Boss 战后选择（±3）、每道第 3 关选择（±1） | 影响结局走向、守道者台词悲凉度 |
| **理性值** | `rationality_value` | 人道第 3 关弃卒保车选择 | 影响人道第 5 关对话 |
| **情感值** | `emotion_value` | 人道第 3 关不牺牲选择（业力 +5 但埋伏笔） | 影响人道第 5 关对话 |

**关键区分**：业力是单局玩法数值（反映"当下的执念重量"），悟道/堕落值是跨关卡人格变量（反映"长期的人格走向"），两者独立。

### 7.5 多结局设计（5 种）

v3.0 在 v1.1 的 4 结局基础上**新增"识破结局"**。

#### 结局 A：悟道结局·破茧成蝶

**达成条件**：
- 悟道值 > 堕落值（差距 ≥ 3）
- 最终选择"理解规则"
- 天道最终战业力 < 100
- **未被识破过**

**剧情**：林夜回到教室，向陈默坦白作弊，陈默早已知道但未揭穿。两人重新对弈，林夜输了却笑得比赢还开心。"规则不是束缚，而是保护。自由不是打破一切，而是在理解之后做出选择。"

#### 结局 B：堕落结局·永堕轮回

**达成条件**：
- 堕落值 > 悟道值（差距 ≥ 3）
- 最终选择"打破一切规则"
- 天道最终战业力 > 200
- **未被识破过**

**剧情**：林夜大笑"终于自由了"，却发现自己还在六道轮回中，六道开始融合变成混沌，林夜的身影被混沌吞噬。"自由的尽头，是虚无。打破一切的人，最终也会被一切打破。"

#### 结局 C：轮回结局·继续修行

**达成条件**：
- |悟道值 - 堕落值| < 3
- 最终选择"还不知道"
- 天道最终战业力中等（100-200）
- **未被识破过**

**剧情**：林夜承认找不到答案，禅定者说"重要的不是答案，而是寻找答案的过程"。林夜回到地狱道起点，但这次不一样了。"我要找到我的答案——用我自己的方式。"
**二周目继承**：技能树全保留 + 轮回记忆 buff。

#### 结局 D：真我结局·与自己和解（隐藏）

**达成条件**：
- 收集全部 6 个记忆碎片
- 每道至少 1 个悟道向选择（累计悟道值 ≥ 9）
- 天道最终战无作弊通关
- 最终选择"理解规则"
- **未被识破过**

**剧情**：六道守道者全部出现，化作六道光芒融入林夜体内。"愧疚、欲望、本能、理性、愤怒、真我——它们不是敌人，而是你的一部分。接纳它们，就是接纳完整的自己。"

**解锁**：真结局 CG、角色设定集、制作人员访谈、"真我"称号。

#### 结局 E：识破结局·天道审判

**达成条件**：
- 玩家在六道轮回中至少被识破过 1 次
- 业力与识破概率被锁死后，仍通关所有六道
- 通关天道后自动触发，**不可选择其他结局**

**剧情**：
> 禅定者：「你曾被识破——业障太重，你的逃避被自己看穿。」
> 禅定者：「但你仍走完了六道。如今，业力已无，作弊已无，只剩你，和我。」
> 禅定者：「来吧——以你本来的样子，与天道一战。」
> 林夜：（深吸一口气）「……好。这次，不靠任何花招。」

**战斗**：天道 Boss 战（详见第四章 4.6）
- 棋类：传统象棋
- 作弊：完全禁止
- 特殊规则：天道无士，士位被车取代（4 车）
- 失败：无限重试

**胜利后**：
> 林夜：（喘息着，看着倒下的"自己"）「……原来，我可以。」
> 禅定者：（微笑消散）「你一直都可以。只是你之前，不敢相信。」
> （画面渐白，林夜回到教室。陈默正在摆棋。）
> 陈默：「林夜？你怎么哭了？」
> 林夜：（擦眼泪，笑了）「没什么。就是……终于赢了自己一次。」

**特殊意义**：识破结局是给"曾经作弊但愿意面对"的玩家的救赎路径——你曾逃避，但最终凭真本事赢回尊重。

### 7.6 业力对剧情表现的影响

**高业力状态**（单局业力 > 100）：
- 主角内心独白更黑暗、更挣扎
- 守道者的台词更具攻击性/诱惑性
- 画面色调偏暗/偏红
- BGM 更压抑/更激烈
- 引路人低语更频繁、更急切

**低业力状态**（单局业力 < 50）：
- 主角内心独白更平静、更清醒
- 守道者的台词更温和/更认可
- 画面色调偏亮/偏蓝
- BGM 更舒缓/更空灵

**机制联动**：
- 某些剧情选项只在高/低业力时出现
- 业力高低影响守道者的"好感度"台词
- 最终结局需要 悟道/堕落值 + 最终选择 双重达标（识破结局除外）
- 记忆碎片只看"全程无作弊通关"条件，与业力绝对值无关

| 棋类 | 触发函数 | 事件 |
|:----:|:---------|:-----|

| weiqi | `_trigger_karma_recover` | 提子（大小）、做活、被提、占角、收官 |
| wuziqi | `_trigger_karma_recover` | 三连、四连、堵三、堵四、双三、胜 |
| dongwuqi | `_trigger_karma_recover` | 普通吃、越级吃、被吃、接近、胜 |
| tiaoqi | `_trigger_karma_recover` | 跳3步、跳5步、入营、单步、全营 |
| heibaiqi | `_trigger_karma_recover` | 小翻、中翻、大翻、占角、被翻、胜 |

每个事件调用 `karma_assessor.decrease_karma(amount, skill_modifiers)` 减少本地业力，同时通过 `/api/karma/event` 同步到 samsara。

### 8.6 数据流与状态同步

```
玩家进入棋类页面
   │
   ▼
main.py /api/command 调用 samsara /api/state
   │
   ▼
同步到本地 karma_assessor:
  set_local_karma_state(karma, karma_max, single_max)
  set_realm_detection(detection, realm)
   │
   ▼
玩家作弊 → 本地 increase_karma → 同步到 samsara /api/karma/consume
玩家走棋 → 本地 decrease_karma → 同步到 samsara /api/karma/event
   │
   ▼
关卡结束 → samsara /api/progression/resolve
  → record_level_end() 计算溢出叠加
  → 若胜利 → advance_realm() → set_realm() 清零溢出
  → 若失败 → 保留溢出，等待重试
  → 若被识破 → 锁死业力/识破概率，标记 detection_triggered
```

## 附录 C：设计原则

1. **业障模型优先**：作弊产生业障，下棋消业。避免"资源管理"式的功利计算。
2. **章节叠加**：迫使玩家在整道内控制作弊节奏，而非单关豪赌。
3. **非线性识破**：小透支可控，大透支必死。鼓励"小步透支"而非"豪赌一次"。
4. **技能持久**：轮回不重置技能树，给玩家长期成长感。
5. **灵活编码**：AI 修改配置而非生成代码，安全可控。
6. **棋类独立**：每棋类独立进程，互不干扰，便于扩展。
7. **预制关卡**：保证游戏体验稳定性，避免纯随机带来的失衡。
8. **多 build 支持**：4 分支技能树支持业力流、隐匿流、作弊流、悟道流等多种玩法。
9. **叙事玩法融合**：六道即人格六面，守道者即主角的投影；悟道/堕落值是跨关卡人格变量，与单局业力独立。
10. **识破即救赎**：被识破不再粗暴重置，而是触发"识破结局"——业力锁死反而使后续通关变易，但天道 Boss 战是终极考验。给"曾经作弊但愿意面对"的玩家提供救赎路径。
