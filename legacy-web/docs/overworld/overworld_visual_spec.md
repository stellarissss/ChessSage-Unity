- `index = 行×12 + 列`；原始单块 `shared/assets/map/<pack>/Tiles/tile_XXXX.png`。
- 记法 `pack#idx`，如 `town#109`。
- **fill=1.00 的砖是满铺地面砖**；fill<1 的是带透明底的物体精灵（树/石/栏/旗等），叠加绘制。
- **大精灵分片警告**：farm#93-95 / 105-107 / 117-119 / 129-131 是一幅 **3×4 大拼片**（巨形绿冠块，
  锚点取 93）；farm#102-104/114-116 与 126-128 是谷仓墙面拼片；battle#59+60 拼成整条河弯；
  dungeon#46+47 拼成双开门。**不得把它们当独立装饰散撒。**
- 本 tileset 为 2.5D 俯视，树/灌/石多为**圆形团块 + 深紫描边**，天然适合叠在地面砖上；
  团块底部大约留 2~3px 透明，绘制时锚点取块底即可。

### 2.10 过渡带通用规则（避免生硬直边）

1. **混色带宽度**：主色差大（雪↔草、沙↔石）用 4 格；相近色（草↔草）用 3 格；带内两区砖池权重线性插值。
2. **交错渐变**：带内不画直线边界——以 `hash(x,y,'ow:v3:edge')<p` 的抖动阈值（p 随带内位置 0→1）逐格切换砖池，
   形成锯齿状咬合；**禁止**按区域 rect 直换。
3. **共享装饰**：过渡带内允许两区点缀物各以 0.5× 密度出现（如密林↔荒原带上朽木与黄灌混生）。
4. **借地貌**：凡过渡带与下列地貌重合，直接以地貌充当边界，不再另做混色：山脊/山脚碎石带、河岸、道路。
5. **tint 类边界**（雪/焦土/暗紫）必须做 alpha 线性衰减带，禁止整区恒定值贴边。

### 3.4 非草地区域岸线（沙漠/雪原/地牢）注意

pond/岸线族的"陆侧"是 battle 草色 `#84c669`：
- **沙漠/地牢**：禁止用 pond 族贴沙——绿边会很脏。改用**中水直邻 + 渲染白沫线**（沿水陆边界画 1px

- **草地系区域**（密林/牧场/平原/丘陵）：直接用 pond/岸线族，色彩天然吻合。

### 3.5 瀑布 / 急流

无专用瓦片。配方：在 2~3 格高差的河断崖处，用 battle#57 的白沫段纵向重复 2~3 块 +
叠加纵向白→透明渐变（`rgba(255,255,255,0.85)→0`，宽 1 格）+ 底部 1 格 battle#37 浅滩 + 白沫圆点。
急流（R-1/R-2 上游）以 #57 连续段 + 波光密度加倍表现。

### 3.6 水面与昼夜

- 烘焙期水面不做昼夜处理；夜间由现有 `ambientLight` 压暗 + Light2d 反射点。

  道境门/火盆辉光在水面 3 格内叠加同色低强度 Light2d（倒光）。

## 4. 山与雪的视觉规则

**禁止**用纯色 `fillRect` 画山（现状问题）。配方：

1. **高岭核心（h≥0.84，不可走）**：dungeon#14 满铺 + dungeon#28（带孔变体，脊顶线）按 3~5 格斑块混合；
   脊线走向用 dungeon#57/58/59 三件拼出纵向棱线。烘焙期按高程着色：`h` 越高叠越暗
   `rgba(30,34,52, k)`（k = 0~0.28），山体自然分出明暗面。
2. **山肩（0.74≤h<0.84，可走 0.55×）**：dungeon#40 + dungeon#24 各半，撒 farm#89 石堆（0.04）。
3. **山脚碎石带（脊线外 band/2~band/2+2）**：dungeon#24 地面 + farm#89（0.06）+ battle#5 土丘（0.02），
   外沿 1 格混入当地草/沙地面砖（《景观设计》§7.4 ×1.30 乘子对应此带）。
4. **雪线**：`h ≥ 0.88-0.30·t` 判雪（《景观设计》§4.2）。雪盖 = 在该格山砖上叠白 tint
   `rgba(240,246,255,0.62)`（山体层单独烘焙，不影响地面层）；北境全区山体直接恒定雪盖。
5. **立体感**：所有山体格按「相邻格高差」在**东南侧**画 2px 深色缘（`rgba(20,24,40,0.35)`），
   西北侧画 1px 亮缘（`rgba(255,255,255,0.18)`）——等效"左上受光"，与 §7.3 的东南椭圆投影一致。
6. **外圈群山（wall 区）**：dungeon#14 + 恒定暗化 `rgba(16,18,30,0.45)`，与可玩区拉开明度差即可，
   不需要细节。

### 8.3 对比度与视觉疲劳

- **对比度**：路牌/告示牌文字（DOM 层）白 `#f5f0e6` on 深棕 `#5c4146` ≥ 7:1 ✓；
  POI 名称浮字加深色描边（2px `rgba(20,16,28,0.85)`），保证在雪原/沙漠浅底上可读。
- **地面噪点控制**（防视觉疲劳，生成器硬约束）：
  1. 每区地面砖池 ≤6 种；权重下限 0.05，低于此并入相邻权重。
  2. 变化砖（泥斑/斑点/沙脊）合计权重 ≤0.30；满铺基砖 ≥0.34。
  3. 选砖以 4~9 格**斑块**为单位（fBm 阈值切分），禁止逐格独立哈希（现状问题，《景观设计》§7.3 已同步）。
  4. 同种满铺砖允许大面积重复；禁止为"丰富"而提高变化砖频率。
  5. 泥斑族（圆斑）叠加密度 ≤0.25/格，避免路面感丢失。
- **动画噪点**：波光/旗/幡的摆动统一 0.5Hz 相位错开，禁止逐格随机相位。
