# 无限制五子棋

> AI驱动的无规则限制五子棋游戏 —— 你可以用自然语言改变一切规则

## 🎮 项目简介

无限制五子棋是一个基于AI的创新五子棋游戏，允许玩家通过自然语言指令实时修改游戏规则、棋子属性和界面外观。这是"无限制象棋"架构上的扩展，展示了如何通过重新设计提示词和配置文件，快速将现有棋类引擎适配为新的棋类游戏。

### 核心特性

- **自然语言规则修改**: 用中文指令改变游戏规则，如"让黑子可以移动"、"六连珠获胜"
- **AI对战**: 内置 Minimax + Alpha-Beta 剪枝 AI，支持多种难度和性格
- **机制引擎**: 支持冻结、AI接管、随机走棋等高级机制
- **无限制修改**: 棋子属性、移动规则、胜利条件均可自定义
- **撤销机制**: 所有AI修改均可撤销

## 🚀 快速开始

### 环境要求

- Python 3.10+
- Node.js (可选，仅用于开发)

### 安装依赖

```bash
cd WuZiQi
pip install -r requirements.txt
```

### 设置 API Key

1. 打开浏览器访问 `http://localhost:8000`
2. 点击设置按钮 ⚙
3. 输入 DeepSeek API Key

### 启动服务

```bash
python main.py
```

访问 `http://localhost:8000` 开始游戏。

## 🎯 游戏玩法

### 基础规则

- 黑子先行，双方轮流落子
- 五子连珠（横、竖、斜）获胜
- 棋盘满且无人获胜为平局

### AI指令示例

```
让黑子变大
让白子可以吃掉相邻的黑子
添加一个禁手规则
在棋盘中心放障碍物
让AI变得更激进
悔一步棋
让对方投降
```

## 🧠 AI系统

### 两层AI架构

1. **意图解析AI**: 将自然语言转化为结构化指令
2. **代码生成AI**: 根据指令生成JSON Patch修改配置

### AI性格系统

| 性格 | 描述 |
|------|------|
| normal | 标准型，攻守平衡 |
| aggressive | 激进型，进攻至上 |
| defensive | 保守型，稳扎稳打 |
| random | 随机型，随心所欲 |
| custom | 自定义型 |

### 机制引擎原语

- `skip_turns`: 冻结某方几回合
- `ai_control`: AI接管某方回合
- `random_moves`: 随机走棋
- `extra_turns`: 额外回合
- `move_limits`: 每回合多步

## 🔧 配置文件说明

### board.json

定义棋盘几何和外观：
- `geometry.width/height`: 棋盘大小（15×15）
- `appearance.background_color`: 棋盘背景色
- `appearance.line_color`: 线条颜色

### pieces_red.json / pieces_black.json

定义棋子规则：
- `pieces.stone.moves`: 移动规则
- `pieces.stone.label`: 棋子显示符号

### rules.json

定义游戏规则：
- `win_conditions`: 胜利条件（五连珠、平局）
- `ai_difficulty`: AI难度配置
